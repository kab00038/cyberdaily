# CyberDaily

Cybersecurity daily news dashboard with threat maps, forecasts, and real-time intel.

## Features
- Real-time cybersecurity news aggregation (RSS feeds)
- World threat map with animated attack arcs
- CISA KEV and NVD CVE threat forecasting
- Hacker News cybersecurity stories
- Dark theme dashboard

## Data Sources
- RSS: BleepingComputer, The Hacker News, Krebs, Dark Reading, SecurityWeek, The Record
- APIs: Hacker News Algolia, CISA KEV JSON, NVD CVE API 2.0, abuse.ch
- All sources are free with no production restrictions

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- react-simple-maps + d3-geo
- Cloudflare Pages deployment
